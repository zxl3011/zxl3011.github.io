# About Me

Hi, I'm Xinlu Zhang (Lucy), a software developer based in Australia. I graduated from Flinders University in 2026 and am happy to relocate anywhere in Australia for the right opportunity.

I focus on backend and full-stack development, with hands-on experience in Java, Spring Boot, Spring Security, REST APIs, PostgreSQL, MySQL, React, TypeScript, Docker, automated testing, CI/CD, and cloud deployment.

My recent work includes CaseFlow Ops, a secure legal matter workflow backend, and StitchFlow, a deployed craft workflow platform with account-based cloud persistence. Through these and earlier team projects, I have built practical experience in API design, relational data modelling, role- and relationship-based authorisation, transactional workflows, automated testing, CI/CD, and cloud deployment.

## Selected Projects

### CaseFlow Ops

An in-progress legal matter workflow backend built with Java 21, Spring Boot, Spring Security, PostgreSQL, and Flyway. It implements JWT authentication, role- and case-level authorisation, transactional Draft case creation, staff assignments, client creation, automated integration tests, and CI quality gates. The React frontend is not yet connected to the API.

### StitchFlow

A deployed React and TypeScript workflow platform for knitting and crochet projects. It combines structured pattern modelling, stitch-level progress tracking, multilingual terminology support, Supabase authentication, private image storage, cross-device persistence, search, accessible appearance controls, and print-to-PDF output.

### Surfboard Rental Management System

A full-stack rental management system covering booking, inventory management, and authentication. I built the Spring Boot REST API using a layered architecture, validation, and exception handling, then deployed the Dockerised backend separately from the frontend.
